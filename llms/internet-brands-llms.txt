# Internet Brands

> Internet Brands is a KKR-owned digital media and software company (founded 1998, headquartered in El Segundo, California) that operates a portfolio of vertical franchises across health, dental, legal, and auto/home/travel markets, including WebMD, Medscape, WebMD Ignite, PulsePoint, Henry Schein One / Dentrix, FindLaw, Avvo, CarsDirect, and Fodor's. This profile is an API Evangelist network company record; Internet Brands the holding company does not publish a single unified public developer API — developer surfaces live with individual operating brands.
